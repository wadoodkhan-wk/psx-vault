Notifications
ntfy.sh topic name
Pick a random, hard-to-guess topic name (anyone who knows it can read your alerts — ntfy topics are public by name).

1. Install the ntfy app on your phone (App Store / Play Store) and subscribe to this same topic name — that's what delivers notifications when this app is closed.
2. Point your n8n workflow's alert step at https://ntfy.sh/<your-topic> via HTTP POST.
3. This app will also show live in-app alerts when open, via the button below.
